# Lists Feature

The Lists feature handles taxonomy browsing and user-generated ranking arrays.

## Key Screens
- `CategoriesScreen`: Displays available taxonomies to rank.
- `ListBuilderScreen`: The interactive drag-and-drop ranking editor.

## Key Components
- `RankingBoard`: Uses `react-native-reanimated` or similar for drag-and-drop lists.
- `FastPickTile`: Pre-populated options avoiding the need for users to type.
