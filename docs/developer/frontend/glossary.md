# Glossary

- **FeedModule**: A logical grouping of content sent by the server, instructing the frontend how to bundle items.
- **ContentUnit**: A polymorphic entity (person, category, insight).
- **River**: A full-width vertical layout.
- **Rail**: A horizontally scrolling layout.
- **Grid**: A wrapping multi-column layout.
- **Spotlight**: A single hero card layout.
